## Issue Summary

Importing a CSV sometimes crashes when a row is missing the email column, raising AttributeError: 'NoneType' object has no attribute 'strip'.

## Likely Root Cause

The parse_user_row function calls email.strip() on the result of row.get("email"), which returns None when the email column is missing, causing an AttributeError.

**Confidence:** high

## Analysis

When a CSV row lacks the email field, row.get("email") returns None. The function then attempts to call strip() on this None value, leading to the observed AttributeError. The same pattern exists for the name field, but the reported failures are triggered by the missing email.
